# Agency and partnership request form

A Persian RTL form was added at `/agency` with:

- Applicant name and company
- Phone and email
- City and province
- Cooperation type
- Company activity description
- Partnership message
- Success state after submit
- Mobile and desktop responsive layout

The current form is a front-end demo: it shows a success state but does not persist submissions. Connect the submit handler to the NestJS API and database for production use.
